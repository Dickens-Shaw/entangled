# Entangled

[English](README.md)

两扇浏览器窗口，两团粒子，一根连线。每个窗口是同一套世界里的一个镜头；同一个编号把 Ethereum 的视角和 Tezos 的视角接在一起。

本地查看器。作品代码来自 Bjørn Staal 的 *Entangled*（fxhash VERTEX，2024），经 [fire17/entangled-grail](https://github.com/fire17/entangled-grail) 从链上文件系统取出。`src/bundle.min.js` 与 `src/fxhash.min.js` 保持原样。这里改的是控制面板和本地启动方式。权利说明见 [NOTICE.md](NOTICE.md)。

## 运行

在线预览：<https://dickens-shaw.github.io/entangled/>

需要两个独立的浏览器窗口。标签页和编辑器内置预览共用一套屏幕坐标，连线对不齐。

```bash
npm install
npm run dev
```

打开 Vite 打印的地址（默认 `http://localhost:8082`）。点角落的按钮展开面板，链那一行末尾的图标会按相同编号打开另一条链。

## 怎么连上

两个窗口通过同源 `localStorage` 交换位置。每个窗口是同一套屏幕坐标里的一个镜头。

连线只在编号相同、链相反时出现：一边 Ethereum，一边 Tezos。同一条链的两个窗口是同一套模拟的两个镜头。编号不同则各自独立。

一个编号就是一套样式。种子是 `1024 * (编号 + 1) + 7`，它决定配色、运动、连接和核心几何。Tezos 的地址编号在 2–256 之间是打乱的，面板上的「编号」是打乱前的样式编号，两扇窗口用的是同一个。

## 改了什么

相对 [fire17/entangled-grail](https://github.com/fire17/entangled-grail) 的 `v0-live` 轮播条，面板换成下面这样。

**悬浮按钮。** 面板默认展开。收起后是 36px 的按钮，透明度 0.28，悬停到 0.92。按钮和面板都可以拖。收起后按钮留在原地：靠右或靠下时，面板从按钮向左、向上展开。

**四个字段。**

| 字段 | 作用 |
|---|---|
| 链 | 以太坊 / Tezos，只改这一扇。后面的图标用相同编号打开另一条链 |
| 配色 | 三个色块只改这一扇。随机让两扇一起换。还原让每扇回到自己这条链、当前编号的原色 |
| 编号 | 1–256，两扇同步。方向键同样改编号。改编号会丢掉临时配色 |
| 质量 | 20–100 的滑条，松开后两扇一起重新加载。粒子数是 150 万乘以这个比例。低于 100% 会关掉抗锯齿和 2 倍内部分辨率 |

`[` 和 `]` 把相邻编号的原色套到这一扇上，不改编号，也不动另一扇。

**地址栏。** 只保留有用的参数：`fxiteration` 和 `fxchain` 一直在。质量为 100% 时不写 `quality`。`noshuffle` 只在旧链接里已经是 `1` 时保留，面板上没有固定 / 洗牌开关。

**窗口名单。** `index.html` 在写入 `localStorage` 的 `windows` 时做合并：一扇窗口保存自己的位置时，会留下另一扇还开着的记录。只有对方标记正在关闭时才移除。

**启动。** Vite 按原文件送出 `index.html` 和 `src/` 里的脚本，不把它们改写成模块。作品是经典脚本，依赖页面上的全局 `THREE` 和 `$fx`。
